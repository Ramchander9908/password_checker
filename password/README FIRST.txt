                                                    ***Guide for using this***

**Password Checker in C
{
A beginner C program that checks whether an entered password has at least 12 characters, an uppercase letter, a lowercase letter, a digit, and one of the listed symbols.
}
**How to run
{
Open `password_checker.c` in a C compiler and run it. Enter a made-up test password when prompted.
}
**Limitation
{
This checks simple rules only; it does not guarantee that a password is secure.
}
